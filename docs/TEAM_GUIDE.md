# Tim od tri clana

Sva tri clana treba da mogu da objasne ceo projekat. Predlog podele je pomoc za organizaciju, ne podela znanja.

| Clan | Primarna odgovornost | Mora dodatno da nauci |
| --- | --- | --- |
| 1 | Neo4j model, `schema.ts`, `seed.ts`, indeksi | API i tok UI zahteva |
| 2 | Recommendation/Graph/Analytics Cypher, GDS | seed semantiku i PROFILE |
| 3 | Next.js, Cytoscape, Swagger, dokumentacija | svaki vazan Cypher upit |

Plan: prvi sastanak zajedno prolazi `GRAPH_MODEL.md`; drugi clan demonstrira seed; treci svima objasni dashboard API pozive. Svako zatim samostalno pokrece sistem od praznog Docker volumena i odgovara na nasumicnih deset pitanja iz odbrane. Dan pred odbranu simulirati 15-minutnu prezentaciju u redosledu iz walkthrough-a, sa promenjenim kandidat ID-jem kako se ne bi oslanjali na zapamcen ekran.
